
Создание персонажа проходит через череду случайных бросков и проверок. Все игроки начинают игру, имея 100 поинтов опыта. Если результат случайного броска не устраивает игрока, он может купить нужный результат за количество очков опыта, указанное в скобках.

#### Родной мир
Сделайте бросок 1D6

| Результат броска | название мира         |
| ---------------- | --------------------- |
| 1-3              | Мидгард (10 поинтов)  |
| 4-5              | Альфхейм (20 поинтов) |
| 6                | Ванахейм (30 поинтов) |

Персонаж автоматически получает ключевую особенность и травму, связанную с его родным миром, но может отказаться от них, как указано в разделе [[3. Разновидности кан#Культуры|Культуры]].

#### Культурные особенности
Сделайте бросок 1D6

| Результат броска | Игрок выбирает культурную особенность из... |
| ---------------- | ------------------------------------------- |
| 1-4              | особенностей родного мира (10 поинтов)      |
| 5-6              | особенностей Лабиринта (20 поинтов)         |

#### Разновидность
Сделайте бросок 1D6. В зависимости от родного мира выберите разновидность

| Родной мир | Результат | Разновидность          |
| ---------- | --------- | ---------------------- |
| Мидгард    | 1-3       | Человек (20 поинтов)   |
|            | 4-5       | Амбистома (40 поинтов) |
|            | 6         | Синтетик (50 поинтов)  |
|            |           |                        |
| Ванахейм   | 1-3       | Кицуне (50 поинтов)    |
|            | 4-5       | Кенку (60 поинтов)     |
|            | 6         | Норанеко (40 поинтов)  |
|            |           |                        |
| Альфхейм   | 1         | Орк (20 поинтов)       |
|            | 2         | Гоблин (10 поинтов)    |
|            | 3-4       | Дварф (30 поинтов)     |
|            | 5-6       | Эльф (50 поинтов)      |

Игрок может купить дополнительный черты, связанные с разновидностями сейчас, или позднее в процессе игры за полученный опыт.
Игрок может получить дополнительные очки, связанные с недостатками сейчас.
Недостатки, полученные в процессе игры, не приносят дополнительных очков. 
#### Призвание

| Результат броска | Призвание                           |
| ---------------- | ----------------------------------- |
| 1                | Воин (10 поинтов)                   |
| 2                | Торговец (10 поинтов)               |
| 3                | Мудрец (10 поинтов)                 |
| 4                | Странник (10 поинтов)               |
| 5                | Изгой (20 поинтов)                  |
| 6                | Игрок может выбрать любое призвание |

#### Характеристики

Все персонажи начинают со стартовыми Характеристиками, равными 6 + 1D6. Дополнительные D6 игрок получает за разновидность, и еще один D6 - за призвание.
